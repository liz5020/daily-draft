用 Claude 做專案工作面板：對話變任務卡＋Skill

AI 對話一多，左邊的列表又臭又長，到底哪件事做到哪、記不記得，變成問題。作者請 Claude 做了一個像 Trello 的「工作面板」，把專案級的對話變成任務卡，再包成 Skill。

他的分工

討論與管理放在 app（手機、電腦都能用），開發級的任務放在命令列版，兩邊用文件溝通。

面板長什麼樣

  • 每個專案一張卡：狀態、下一步、子任務、AI 對話連結、最後活動日。
  • 統計：進行中的有幾個、超過 14 天沒動的有幾個、沒有下一步的有幾個、子任務完成度；並提醒「同時進行不超過 3 個」。
  • 分頁有全部、進行中、構想、暫停、完成，還能依領域篩選。

從截圖看得到，他的面板上有十多張卡，例如 TOEIC 十一月重考、LINE 記帳機器人、音效庫工具、仙台機票查詢等；每張卡都有對話連結和子任務進度條，也標出幾天前還有活動。面板上寫著進行中有 11 個、超過 14 天沒動的有 7 個、沒有下一步的有 11 個，並說「沒有下一步」是最容易被忘記的。

做成 Skill 之後

Skill 可以串接所有對話；對話中一出現規劃討論，Claude 會主動問要不要轉成任務卡。例如他說想去仙台查機票、回台灣做體檢，Claude 就把這兩件加進「構想」，並建議子任務（確定日期、比較方案、訂票或預約）。

好處與限制

好處是跨平台，手機或電腦都能用對話更新進度、調出某個專案的對話；作者用了一週，覺得推進度的效率提升不少。不過這是他一週的主觀感受，工具也沒有公開，不能直接下載使用。

可以怎麼用

不必做面板也能學：把你手上同時進行的專案列出來，每個寫一句「下一步」，數數看有沒有超過三個。

來源與備註：Threads 帳號 @rfyao5083，2026-11-09 發文；個人自製工具，沒有公開連結。

給 Claude Code 的指令

適合情境：你同時有很多 AI 對話與專案，常忘記做到哪裡時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

請幫我設計一個「專案工作面板」的做法，先不要寫程式。1. 先問我目前同時進行的專案（我會列給你）。2. 為每個專案整理出：狀態（進行中／構想／暫停／完成）、下一步、2～5 個子任務、最後活動日。3. 用一張 Markdown 表格呈現，另外標出「超過 14 天沒動」與「沒有下一步」的專案，並提醒我同時進行的不要超過 3 個。4. 之後我只要在對話中說「更新面板」，你就依我說的進度更新這張表。

貼進 Claude Code 後，它會先列出要改什麼、等你說「好」才動手。同一份指令也存在原筆記的「給 AI 的指令」。
