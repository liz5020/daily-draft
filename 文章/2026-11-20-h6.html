AI 做的 HTML 網頁怎麼分享

用 AI 做了一頁很漂亮的 HTML，卻只能把檔案傳來傳去，別人還得下載、解壓、打開。ChiYu 的教學說：用 GitHub Pages，全程在網頁上操作，就能把它變成一個點開就能看的網址。

步驟細節

  1. 註冊 GitHub 帳號，帳號名稱會變成網址的一部分。
  2. 建立 Repo，選 Public，打開 Add README。
  3. Add file → Upload files，上傳 HTML。
  4. 把檔名改成 index.html，否則首頁會變成 README。
  5. Settings → Pages，Branch 選 main、資料夾選 /(root)，按 Save。
  6. 部署完成後，網址是 https://帳號.github.io/Repo名稱/。
  7. 改版時重新上傳同名的 index.html 覆蓋，網址不變。

限制要記得

  • 免費帳號的 Repo 必須公開，原始碼與修改紀錄都看得到，不要放 API 金鑰或個資。
  • 不適合做生意、收款或處理敏感資料。
  • 只能放靜態檔案，沒有後端或資料庫。

可以怎麼用

找一個你用 AI 做過、沒有個資的小頁面（例如活動說明或作品集），今天照步驟 1～3 先把它放上去，其餘明天再做。

來源與備註：Threads 帳號 @chiyuisme，2026-11-14 發文；完整教學在作者自己的部落格，是教學文，不是推廣。

給 Claude Code 的指令

適合情境：你用 AI 做了一頁 HTML，想把它變成一個可分享的網址時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

我有一個用 AI 做的單頁 HTML 想放到 GitHub Pages。請你先檢查檔案：1. 有沒有 API 金鑰、密碼、電話、地址、信箱等個資，有的話先列出來，不要自己刪也不要上傳；2. 檔名是否為 index.html，圖片與樣式的路徑是否是相對路徑；3. 用白話列出「從註冊 GitHub 到拿到網址」的步驟，一步一件事，讓我在網頁上照做；4. 提醒我免費帳號的 Repo 必須公開。先不要執行任何上傳動作，只給檢查結果與步驟。

貼進 Claude Code 後，它會先列出要改什麼、等你說「好」才動手。同一份指令也存在原筆記的「給 AI 的指令」。
