Claude Cowork 搭配 MCP 與 Skill 的六個工作用法

很多人聽到 MCP、Skill 就覺得要會寫程式才用得到。Threads 設計創作者 kevin_learn 的說法是：在 Claude 的 Cowork 裡，這兩個功能都是用點選和對話設定的，設定好之後，Claude 可以讀信、整理檔案，還能照你習慣的格式交出成果。他整理了六個新手最容易上手的組合。這篇值得細看，是因為它把三個常被混在一起的名詞講清楚，並且每個用法都附了具體步驟。

先搞懂三個名詞

  • Cowork：讓 Claude 動手做事的模式。在電腦上指定一個資料夾，它就能讀取、修改、整理裡面的檔案，最後把成果存回同一個地方。
  • MCP（在 Claude 裡叫「連接器」）：讓 Claude 接上 Gmail、Google 試算表、Notion、Canva 這些工具的插座。接上之後它能讀資料，也能在你同意後幫你動手。
  • Skill：把你做某件事的方法寫成一份說明書（SOP）。下次遇到同類工作，Claude 會自己翻出來照做，不用每次重講一遍。

六個用法

  1. 只用 Cowork，把格式不同的檔案整理成一份：作者舉的例子是客戶給的設計需求與修改回饋，有純文字、PDF、簡報。做法是把檔案放進同一個資料夾、在 Cowork 選這個資料夾、說明想怎麼整理，結果還能再微調。省下的是一份份打開、複製、貼上的時間，之後有問題也能隨時追問。
  2. Cowork＋Gmail＋Notion，做訂閱扣款提醒看板：在連接器頁面接上 Gmail，請 Claude 找出訂閱、續約和扣款通知信，再整理進 Notion 資料庫：服務名稱、金額、下次扣款日、用哪張卡。作者說同樣的做法也能拿來記帳。
  3. Cowork＋Google 試算表或雲端硬碟，每週固定彙整：第一次先詳細說明要讀哪幾份檔案、整理成什麼格式，確認沒問題後請 Claude 設成排程，例如每週一早上跑一次。作者說排程在雲端執行，電腦睡著或桌面版關掉也照跑；只有要讀電腦裡的本機檔案時才需要開著電腦。
  4. Cowork＋Slack，每天早上先看訊息重點：接上 Slack 後，請 Claude 讀累積的未讀訊息，列出需要回覆的與新交辦的事項，讓人一開工不怕漏東漏西，也可以請它接手處理其中的工作。
  5. Cowork＋Claude Design，把研究做成輪播圖：先讓 Claude 上網找資料或讀資料夾檔案、整理重點，再請它用內建的 Claude Design 做成輪播圖，例如 5 張 IG 輪播。可以附參考圖或過去作品讓風格接近；大方向用對話改，細節直接在畫面上留言或拖拉；不確定方向時請它一次給 2 到 3 個版本；滿意後匯出 PDF 或 PNG。
  6. 用 Skill 收做法：前面幾個用法，第一次做都要花時間講清楚，Skill 就是把講過的東西存起來。作者自己做 IG 輪播圖就是先給參考圖、確認 Claude 理解，再請它把流程建成 Skill，之後只要丟主題和內容，就照同一套風格產出。做法是先把一件事做好，再說「幫我把剛剛的做法做成一個 Skill」，Claude 會問幾個問題後寫好說明書；存好後到 Skills 設定確認已開啟，也可以輸入「/」叫出來。
不要太早做 Skill：先把成果做到你滿意，再收成 Skill；一份還沒想清楚的說明書，反而會干擾 Claude。

組合起來，就是專屬流程

這些用法可以疊在一起。作者的例子是：每週一早上，排程任務自動讀 Gmail 裡的訂閱通知，照做好的 Skill 格式更新 Notion 的扣款看板，你只要打開來看就好。整個流程不用寫程式，全部在 Cowork 裡用對話和點選完成。

開始前要知道的四件事

  1. 作者說 Cowork 需要 Claude Pro 或以上的付費方案，建議用桌面版；要讀電腦裡的檔案時，桌面版要開著。
  2. 只給需要的資料夾和工具，不用一開始就把整台電腦、所有帳號都接上。
  3. 寄信、刪檔、改行程這類動作，先讓 Claude 給你看過再執行。
  4. 先從一件每週都在重複做的小事開始，流程順了再建立下一個。

留言提醒：名稱可能已經變了

有讀者留言說「好像已經沒有 Cowork 了」。作者回覆：他前兩天寫這篇時還看得到，後來確認現在統一叫 Claude，也沒有 Chat 的選項，感覺是默默合併了。這點提醒我們：介面名稱會變，重點是理解「做事、工具、做法」三層分工，而不是死背按鈕位置。

怎麼看待這篇

這篇是教學型分享，優點是把抽象名詞配上生活化的例子，而且最後給了防呆原則：只開需要的權限、有副作用的動作先預覽。需要留意的是，文中的產品介面、步驟與方案限制都是作者的描述，產品又更新得快，實際使用前請以 Anthropic 官方說明為準。

可以怎麼用

挑一件你每週都重複做的小事（例如整理某個資料夾裡的檔案），先用對話請 Claude 做一次，做到滿意再說「幫我把剛剛的做法做成 Skill」。今天只做第一步：決定是哪一件事，並把需要的資料夾放在一起。
