把 Obsidian 當 AI 的長期記憶：Codex＋Hermes 第二大腦做法

很多人學了一堆東西，要用時卻找不到：資料、想法、工作進度散在不同地方。這篇作者的做法是把 Obsidian 當成 AI 的「長期記憶層」，再接上 Codex 與 Hermes 兩個工具幫你做事。它從怎麼整理資料夾、裝哪些外掛，一路講到學習、內容創作、工作自動化三個實例，適合已經在用 Obsidian、想讓 AI 真正派上用場的人。

為什麼是 Obsidian

作者列出的理由是：知識可以沉澱、重複使用；可以追溯、擴充；資料存在自己的電腦裡由自己掌控；AI 讀取格式穩定（本機 Markdown）。Obsidian 本身的核心功能包括雙向連結、Graph View、全文搜尋、Daily Notes、Templates 與插件生態。三者的角色是：Obsidian 是長期記憶，Codex 是調度核心，Hermes 是執行領隊。

新手第一步：先整理 Vault

作者建議的資料夾編號如下：

  • 00_Inbox：還沒整理的收件匣
  • 01_Projects：進行中的專案
  • 02_Areas：長期維持的領域
  • 03_Resources：參考資料
  • 04_SOPs：標準流程
  • 05_Skills：技能與做法
  • 06_Memory：給 AI 的記憶
  • 07_Daily Notes：每日記錄
  • 08_ARCHIVE：封存

三個習慣：命名規則統一、用 Templates 讓格式一致、養成 Daily Notes。重點提醒是「SOPs、Skills、Memory 分開放，AI 更容易讀」，資料夾命名統一，之後搜尋與自動化才會準。另一個小技巧：每篇筆記只放一個主題（例如「N5 日文單字」「每日學習」分開寫），再用雙向連結串起來；複雜概念、學習流程、心智圖可以用 Excalidraw 直接畫，不用硬打字。

可以先裝的外掛

  • Obsidian Web：網頁剪藏，選取文字送進 Obsidian
  • Sidenote2 Obsidian：側欄快速記下靈感
  • WebClipper：長文保存與標註整理
  • Local REST API：讓 Chrome 與 Obsidian 溝通，要先裝它。作者自己也提醒這需要了解安全風險，按需要才加裝

順序是先裝 Obsidian Web 加 Local REST API，其他工具之後再說。

三個應用例子

例子 1：學習整理

流程是上課筆記、AI 整理重點、建立複習清單、決定下次行動。筆記分成記下（重點、問題、例子）、整理成（摘要、重點、待查資料），考前直接看複習頁，不必重翻全部。學日文時，單字、文法、例句、複習清單放在同一頁，語言筆記固定四欄：單字、文法、例句、複習；每晚回看 10 分鐘，每次學完用 5 分鐘補一頁「今日學到什麼」。

例子 2：內容創作

把靈感庫、Hook（吸引停留的開場句）、Caption、Hashtag、圖片 Prompt 收進同一個內容庫。IG 或 Threads 的題材先存起來，不怕忘；爆款結構拆成模板，下次直接重用；AI 協助改寫語氣、整理 9 宮格腳本。模板固定五欄：主題、痛點、Hook、CTA、素材。作者的示範是「寵物店日常」：主題「夏天帶貓出門的小提醒」，痛點「主人怕熱、怕緊張」，Hook「第一次帶貓出門，最怕不是不乖，而是太熱」，再同一頁產出 IG 貼文、Threads 文案與圖片 prompt；也可以先寫長版 IG 再濃縮成 Threads。

例子 3：工作自動化

流程是客戶需求進 Obsidian（規則與 SOP），Codex 寫工具，Hermes 執行流程。例如處理工作進度與客戶購買紀錄：每日記錄、匯入購買表、Codex 整理、Hermes 跟進。

進階：把 Obsidian 變成 AI 的記憶層

建立 Rules、SOP、Clients、Templates 這幾個資料夾，讓 AI 每次都照裡面的規則做事；AI 做錯時，就把修正後的結果寫回規則頁，下次不會再犯。

避坑清單

  • 不要一開始就裝一堆外掛
  • 不要同一個 Vault 同時用多個雲端同步
  • 不要兩個裝置同時修改同一篇筆記
  • 定期備份

需要留意的地方

這是作者的個人經驗，工具組合與效果沒有第三方數據；貼文沒有說明 Hermes 到底是哪個產品，實際用之前要自己確認。Local REST API 會開啟本機連接埠，要注意金鑰與安全。

可以怎麼用

今天只做一件事：在自己的 Vault 裡建一個 06_Memory 或 Rules 資料夾，寫三條「AI 做錯過就不要再犯」的規則，下次叫 AI 做事時請它先讀這個資料夾。

來源與備註：Threads 帳號 corpenpremier（Corpen Premier 職場高效），2026-06-29 發文，12 頁輪播；留言區的教學索取導流已略去。

給 Claude Code 的指令

適合情境：想讓 Claude Code 讀你的 Obsidian 資料夾並照規則做事時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

請幫我檢查我的 Obsidian Vault（資料夾路徑：請先問我）。步驟：1. 列出現有資料夾結構。2. 對照這個建議架構：00_Inbox、01_Projects、02_Areas、03_Resources、04_SOPs、05_Skills、06_Memory、07_Daily Notes、08_ARCHIVE，告訴我哪些已有、哪些缺、哪些可合併，先不要搬動任何檔案。3. 在 06_Memory 建一個『AI 規則.md』，先放三條空白規則欄位讓我填。4. 告訴我下次你開工時要先讀哪幾個檔案。做完用白話列出你改了什麼。

貼進 Claude Code 後，它會先列出要改什麼、等你說「好」才動手。同一份指令也存在原筆記的「給 AI 的指令」。
