ui-ux-pro-max-skill：做網頁前，先讓 Claude Code 配好設計

Claude Code Everyday 第 113 天介紹 GitHub 上的 ui-ux-pro-max-skill：裝好後，叫 Claude 做網頁或介面時，它會先配好結構、風格、配色與字型，再動手寫程式，而不是直接給你一個預設樣式的頁面。

它先做什麼

寫程式前先產生一套設計：結構（首頁分哪幾塊）、風格（從風格庫挑）、配色（依產品類型配一整組）、字型（標題與內文組合）、避免（這類產品別犯的設計錯）。它同時是一個 skill 與 Claude Code 外掛，授權 MIT。

三步裝好

  1. /plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
  2. /plugin install ui-ux-pro-max@ui-ux-pro-max-skill
  3. 直接說要做的網頁，它自己啟動。

裝之前先知道

  • 電腦要有 Python 3，搜尋腳本才跑得動。
  • 沒指定技術就做成一般網頁（HTML 加 Tailwind）；支援網頁、手機、桌面程式共 22 種技術，如 React、Vue、SwiftUI。
  • 既有專案指定一種風格，就能換主題。
  • 作者整理頁寫的資料庫規模：84 種風格、192 組配色、74 組字型搭配與 UX 準則，共 7 個 skill。

實際設計品質是否真的比不裝好，目前沒有查到獨立評測；專案的星數作者當日讀到約 14.7 萬。

可以怎麼用

找一個小的網頁需求（例如一頁自我介紹），先不裝、請 Claude 做一版，再裝了重做一版，兩個並排比較。

給 Claude Code 的指令

適合情境：你想讓 Claude Code 做出的網頁比預設樣式更有設計感時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

我想試用 ui-ux-pro-max-skill 這個外掛。請先確認我的電腦有裝 Python 3，沒有的話告訴我怎麼裝，不要自己執行任何刪除動作。接著帶我執行這兩個指令：/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill 與 /plugin install ui-ux-pro-max@ui-ux-pro-max-skill。裝好後，請用它幫我設計一頁簡單的自我介紹網頁：先列出你選的結構、風格、配色、字型與要避免的錯誤，我確認後再動手做。
