文獻小助理：用 Claude 做段落搜尋，並匯出證據

寫論文或報告時，最累的是「我記得哪裡看過，但找不到出處」。作者請 Claude 幫她做了一個「段落搜尋」小工具：丟一句話，它到 PDF 文獻庫逐頁翻，標好相關度與頁碼，最後把證據整理好，寫 Word 時一鍵引用。她最在意的一點是：每個結果都能回頭核對，而不是只相信 AI 的轉述。

步驟一：搜尋

  • 問一句話，從整個 PDF 文獻庫逐頁比對。
  • 結果標出證據編號、相關度、作者（年份）與頁碼，以及一句判斷（例如「直接回答問題的實證結果」）。
  • 外文段落自動附繁體中文翻譯，僅供理解；可以直接開 PDF 到該段，並有原文反白截圖對照。

步驟二：匯出

確認要用才產生檔案。資料夾依日期與提問命名，裡面有：每段一頁的證據 PDF（頁首標好引用與頁碼）、反白截圖、附書籤的合併 PDF，以及總表。證據編號像「26110701E0001」，讀法是：日期、當天第幾次搜尋、第幾段。

步驟三：引用

寫 Word 時選一句話、按快速鍵、輸入編號，旁邊就跳出註解，內含編號、作者（年份）、頁碼與證據連結，點一下就回到原文那頁；可選擇把截圖放進文末附錄，定稿時可一鍵刪除所有註解。

可以怎麼用

不必先做完整工具。今天先挑 3 份 PDF，請 AI 回答一個問題，並要求它「每個答案都附頁碼與原文句子」，自己抽一個回去核對，感受這個流程。

來源與備註：Threads 帳號 niensvlog_127 於 2026-11-07 分享，屬作者自製的個人工具，沒有附程式碼；AI 仍可能漏找或誤判相關度，所以要保留原文截圖核對。

給 Claude Code 的指令

適合情境：你有一批 PDF 文獻，寫報告時想快速找原文段落、保留頁碼好回頭核對時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

請幫我在這個資料夾的 PDF 文獻裡做「段落搜尋」。我會丟一句問題給你。你要：1) 先想出相近的同義詞一起搜；2) 逐份 PDF 找出相關段落；3) 每個結果列出：編號（日期＋當天第幾次搜尋＋第幾段）、作者（年份）、頁碼、原文段落、相關度（高／中／低）與一句判斷理由；4) 外文段落附繁體中文翻譯，標明僅供理解；5) 找不到就直接說找不到，不要編。等我說「匯出」，再把結果整理成一個新資料夾裡的 Markdown 總表（只新增檔案，不修改或刪除我原有的任何檔案）。

貼進 Claude Code 後，它會先列出要改什麼、等你說「好」才動手。同一份指令也存在原筆記的「給 AI 的指令」。
