diagram-design：給 AI 寫程式工具用的架構圖 Skill

想請 AI 幫你畫架構圖，卻總是得到醜醜的預設樣式？diagram-design 是 GitHub 上的一個開源 Skill，讓 Claude Code、Codex、Cursor 等工具直接輸出乾淨的圖。

它是什麼

  • 輸出單一檔案的 HTML 加 SVG，不靠 Mermaid。
  • 強調沒有陰影、沒有多餘的線，截圖可以直接放進簡報或 PR 說明。
  • 支援套用自己的品牌配色與字體。
  • 圖的種類很多，例如架構圖、流程圖、時間軸、象限圖、組織圖、甘特圖等。

數字不一致的地方

貼文說有 44 種圖表，但專案頁面自己前後寫的是 45 與 50，其他來源也有 29、38 等說法，可能是不同版本。星數也在快速成長（貼文 10 月 12 日寫 51,004 顆，之後頁面已超過 6 萬）。

使用時注意

  • 只認這一個官方 repo，其他名稱的版本視為非官方。
  • 預設字體從 Google Fonts 載入，離線時要改系統字體。
  • 授權為 MIT。

可以怎麼用

挑一張你最近想畫的流程，請 AI 用這個 Skill 做一份，再和你平常拖方塊畫的版本比較。

來源與備註：@easyanythinghk 於 2026-10-12 在 Threads 轉介紹；GitHub 頁面內容已對照，各數字以頁面為準。

給 Claude Code 的指令

適合情境：需要畫架構圖或流程圖放進簡報、說明文件時

請先讀懂下面的需求，列出你打算讀哪些檔案、改哪些地方、步驟是什麼，等我說「好」再動手；不要直接修改或刪除任何檔案。

請先看看這個專案的結構與 README，然後幫我用乾淨的 HTML＋SVG 畫一張架構圖：
1. 先列出你看到的主要模組與它們之間的關係，讓我確認。
2. 確認後，畫成單一的 HTML 檔，不要陰影、不要多餘線條，文字手動斷行、不超出方塊。
3. 有先後順序的地方才用箭頭，並列的項目不要用箭頭。
4. 圖放在新資料夾裡，不要改動現有檔案。
如果我另外給了配色與字體，請套用。

貼進 Claude Code 後，它會先列出要改什麼、等你說「好」才動手。同一份指令也存在原筆記的「給 AI 的指令」。
