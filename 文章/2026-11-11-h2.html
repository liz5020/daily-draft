Obsidian 執行長把自己的第二大腦免費放上 GitHub，四個值得抄的做法

不想從空白頁開始想「資料夾怎麼分」？Obsidian 的執行長 kepano 把自己在用的筆記庫範本整包放上 GitHub，免費下載。介紹這個範本的作者從他的說明裡挑出四個最值得抄的做法，這些做法的共通點是：把整理的力氣省下來，花在連結與回顧上。

怎麼拿到範本

  1. 到 GitHub 搜尋 kepano-obsidian。
  2. 按綠色「Code」→ Download ZIP，解壓縮。
  3. 打開 Obsidian，選「開啟資料夾作為儲存庫」，指向剛解壓縮的資料夾。

Obsidian 本身免費，筆記就是存在你電腦裡的一般文字檔。

四個值得抄的做法

① 資料夾很少

大部分筆記直接放最外層，因為一則筆記常常同時屬於好幾類，分了資料夾反而找不到。要分類，就在筆記上加一個「分類」欄位，同一則可以同時是「書」也是「工作」。

② 連結用好用滿

第一次提到的人、書、地點，就加上連結；還沒寫的筆記也先連，之後自然會串起來。

③ 日記不是拿來寫的

每天一頁，內容幾乎是空的，用途是讓其他筆記連過來，回頭看那天發生了什麼。

④ 什麼都打 1 到 7 分

書、電影、餐廳都打分。他說 10 分太細，7 分剛好分得出好壞。另一個習慣：每隔幾個月隨機翻一則舊筆記，順手把連結補好，這件事他刻意不交給程式自動做。

還有兩樣免費的

  • 每年底問自己的 40 題，有多國語言翻譯。
  • Obsidian 主題 Minimal，畫面很乾淨。

下載前的提醒

範本的 README 在某個版本曾被回報步驟有誤，若照做遇到問題，可以先看 GitHub 上的 issues。以上四個做法是介紹者的轉述，細節以 kepano 的原說明為準。

可以怎麼用

不必整套照抄。今天挑一個：打開最近寫的一則筆記，把第一次出現的人名或書名加上連結，就完成了做法 ②。

來源與備註：Threads 帳號 @good_job_ai，2026-11-10 發文，內容為作者轉述 Obsidian 執行長 Steph Ango（kepano）範本的說明；範本在 GitHub 上確實存在，「5,250 顆星」等數字為作者自述，部分數字未查到出處。
